# Project instructions

- Read README.md and PLAN.md before making changes.
- Complete one coherent implementation step, run focused validation, update PLAN.md, and commit it before starting the next step.
- Push completed commits when the authenticated private remote is available; never force-push.
- Label synthetic fixtures explicitly. Do not report fixture tests as validation on real MaleCNS data.
- Record provenance for all biological data and document model assumptions.
- Do not commit secrets, raw bulk datasets, local environments, or generated traces.
- Keep a simple CPU execution path; add acceleration only after profiling.
